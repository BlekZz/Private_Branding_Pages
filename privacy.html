Privacy Policy

Last updated: 2026-10-07

This policy covers the personal tools listed on the home page, including rclone-media-workspace. These tools are operated by a single individual for their own use only.

1. Data accessed

With the user's explicit consent through Google's OAuth screen, the tool accesses the Google Drive API using the drive.file scope. This scope only allows access to files and folders that the tool itself created. The tool cannot read, list, or modify any other content in the user's Google Drive.

2. How data is used

Files are uploaded from and downloaded to the user's own computer, solely to back up and synchronize the user's own media files. File names, sizes, and checksums are read only to decide what needs to be transferred and to verify transfers.

3. Storage and sharing

  • Data is transferred directly between the user's computer and the user's Google Drive. There is no intermediate server.
  • OAuth tokens are stored only in the local rclone configuration file on the user's own computers.
  • No data is sold, shared with, or disclosed to any third party.
  • No analytics, advertising, or tracking of any kind is used.

4. Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

Files remain in the user's Google Drive until the user deletes them. Access can be revoked at any time at myaccount.google.com/permissions; deleting the local rclone configuration removes the stored tokens.

6. Changes

Changes to this policy are published on this page with an updated date. The full history is available in the repository history.
