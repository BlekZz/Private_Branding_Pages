This site is the public home page for a small set of personal, non-commercial tools operated by a single individual (GitHub: BlekZz). These tools are not offered to the public and have no other users.

rclone-media-workspace

A private configuration of the open-source file sync tool rclone, used by its owner to back up and synchronize their own media production files (video footage, narration audio, finished renders) between their own computers and their own Google Drive.

  • Google API used: Google Drive API
  • OAuth scope: https://www.googleapis.com/auth/drive.file — access is limited to files and folders this tool itself creates. It cannot see or modify any other file in the user's Google Drive.
  • Who uses it: only the owner, on their own computers.
  • Where data goes: directly between the owner's computer and the owner's Google Drive. No server, third party, or analytics is involved.
